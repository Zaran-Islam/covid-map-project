# COVID-19 Data Visualization

An interactive visualization of COVID-19 data across the United States.

## Technologies

- HTML
- CSS
- JavaScript
- D3.js
- CSV Data
- TopoJSON

## Features

- Interactive U.S. map
- State-level COVID-19 data
- COVID-19 cases and deaths
- Top 10 states bar charts
- Interactive timeline brush
- State tooltips
- Data table

## Data

The project uses COVID-19 and U.S. Census datasets provided for the project.

## How to Run

Open `index.html` using VS Code Live Server.
