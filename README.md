## COVID-19 Visualization of Data

An interactive visualization of COVID-19 data across the United States. ## ## Technologies
- HTML
- CSS
- Javascript
- D3.js
- CSV Data
- TopoJSON

## Functions

- Interactive map of US
- COVID-19 Data by State- COVID-19 cases and death
- Top 10 states bar charts
- Interactive timeline slider
- State tooltip
- Data table Use

### Maps and Atlases

- Hover over a state to get information on that state including population, COVID-19 cases, deaths and percentages.
- Click on a state to select it, and highlight the state in the visualization.
- On the right are bar charts of the states with the most COVID-19 cases and deaths.

### Timeline
- Click on the timeline at the bottom of the page to select a date range.
- Click and drag on the timeline to select the time period you want to view.
-The map and bar charts will update automatically to show COVID-19 data for the time period that you select.
- You can pick a shorter or longer period of dates depending on what you want to analyze.
- Click the **Reset** button to revert to the full time period.

### Diagram
- Click **Switch to Table** to see COVID-19 data in a table format.
- This table presents cases, deaths and population by state.
- Select **Switch to Map** to return to the interactive map.

## Data availability

The project uses U.S. Census data and COVID-19 data provided for the project.
